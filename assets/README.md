## Final banner prompt

The built-in tool edited the initial combined-vehicle illustration using this final prompt:

> Edit this existing wide README banner. Preserve the rover, underwater ROV, terrain, water, materials, lighting, composition, color palette, and overall dimensions. Change only the heading area: remove the word MESEKET completely, make CONTROL STATION the single large main heading in the upper center, and retain MARS ROVER + UNDERWATER ROV as the smaller subtitle underneath. There must be no MESEKET or MESKET text anywhere and no duplicate CONTROL STATION line. Exact final text: 'CONTROL STATION' and 'MARS ROVER + UNDERWATER ROV'. Keep the typography polished and readable with generous spacing. Do not add any other text, logos, or watermarks.

The initial illustration brief specified a wide cinematic engineering composition with a four-wheeled red Mars rover on rocky terrain and a compact six-thruster open-frame ROV in blue water. The vehicles are conceptual representations rather than an exact hardware model.
